# Nota Windows SmartScreen

M.G Windows Toolbox 0.3.0-beta.1 è una Beta non firmata digitalmente. Per questo Windows può mostrare un avviso SmartScreen al primo avvio.

L'avviso non indica automaticamente che il file sia dannoso: segnala che l'app non possiede ancora una reputazione/certificato di firma riconosciuto da Microsoft.

Prima di avviare il programma:

1. scaricalo esclusivamente dalla release ufficiale;
2. confronta l'hash SHA-256 con `SHA256SUMS.txt`;
3. verifica che il file sia `M.G Windows Toolbox.exe` nella cartella distribuita.

Non sono inclusi bypass di SmartScreen e non viene richiesto all'utente di disattivare le protezioni Windows.
