## Windows and optional external tools

M.G Windows Toolbox invokes Windows-provided tools such as WinGet, DISM, `powercfg`, `pnputil` and `netsh`. It does not bundle their source code or binaries. VirtualBox and its `VBoxManage` tool are used only when separately installed by the user and are not included in this package.
